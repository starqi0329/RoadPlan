# 真机验收

在自己的 Windows 上运行切片 3 合进 `slice/3` 之后的开发版。发布版会忽略 `SHIXU_FAKE_NOW`。

先把时间固定成上午已经开始、下午还没到的时刻：

`SHIXU_FAKE_NOW=2026-11-26T10:42:00+08:00`

写这份清单时，复盘界面还没合进来。结果先空着。

| 步骤 | 期望 | 结果 |
| --- | --- | --- |
| 用上面的时间打开程序 | 能看到 2026-11-26 的日计划，时间停在 10:42 | 未在本机执行 |
| 打开上午复盘 | 可以写笔记并保存。没有「评分」，也没有大模型或 AI 的结论、建议 | 未在本机执行 |
| 打开下午复盘，再打开晚间复盘 | 都写着「该时段尚未开始」。保存不可用，或者保存后明确失败，界面上不出现一份已经保存的复盘 | 未在本机执行 |
| 把时间改成 `2026-11-26T19:00:00+08:00` 再打开晚间复盘 | 可以写笔记并保存。能看到当时的统计：计划数、完成、跳过、逾期、专注分钟。仍然没有评分和 AI | 未在本机执行 |
| 保存之后，再去把一条相关计划标成完成，回到刚才那份复盘 | 笔记还在，五个统计数字不变 | 未在本机执行 |
| 只改这份额笔记再保存 | 笔记变了，五个统计数字仍不变 | 未在本机执行 |
| 对同一个目标写两份复盘 | 列表里有两份，后写的在前面。改其中一份的笔记，另一份和统计都不变 | 未在本机执行 |
| 在晚间复盘的明天区域，把一条还没做完的今天计划改到 2026-11-27 | 今天原来那条变成已跳过，并写明已改期到 2026-11-27。明天有一条新计划，没有完成结果 | 未在本机执行 |
| 把一条已经完成、写了备注的今天计划复制到明天 | 明天多一条。它没有完成结果，备注是空的。今天那条仍是完成，备注还在 | 未在本机执行 |
| 在明天直接新建一条计划 | 明天能看到它 | 未在本机执行 |
| 切换到明天的日计划 | 能看到刚改期、复制和新加的那几条，不需要关掉重开才出现 | 未在本机执行 |
| 把复盘页面从上到下看一遍 | 任何位置都没有评分、星级、置信度，也没有 AI 或大模型写的总结 | 未在本机执行 |
