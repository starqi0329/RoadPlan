# 真机验收

在自己的 Windows 上运行这条合进之后的开发版。看的是「最小化」和「×」是不是两件不同的事。提醒、导出、开机自启不在这次范围内。

写这份清单时，正式路径还没合进来。结果先空着。请同时打开任务管理器，方便看进程还在不在。

| 步骤 | 期望 | 结果 |
| --- | --- | --- |
| 打开开发版，看顶栏 | 能分清「最小化」和「×」。不是只剩一个含糊的方框 | 未在本机执行 |
| 点「最小化」 | 整扇主窗从桌面消失，不是只留一条顶栏杠。程序还在。任务栏上还有这个程序的图标。系统托盘里这不是「关掉进托盘」 | 未在本机执行 |
| 点任务栏上的图标 | 完整主窗回来：顶栏、左轨、主区都在，不是空壳 | 未在本机执行 |
| 点顶栏「×」 | 主窗消失，进系统托盘。任务管理器里进程还在。任务栏上不是停在刚才那种最小化 | 未在本机执行 |
| 托盘菜单里选「打开主窗」 | 完整主窗回来，顶栏、左轨、主区都在 | 未在本机执行 |
| 再点一次「×」 | 再次进托盘。这一次仍然有效，不是点了没反应 | 未在本机执行 |
| 托盘菜单里选「退出」 | 进程结束。托盘图标消失。要再用必须重新启动 | 未在本机执行 |
| 重新打开后，先点「最小化」，再从托盘选「打开主窗」 | 若产品允许这条：主窗完整回来，不崩溃，不是空壳。若产品不做，记「不适用」 | 未在本机执行 |
