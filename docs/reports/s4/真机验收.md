# 真机验收

在自己的 Windows 上运行切片 4 合进 `slice/4` 之后的开发版。这一阶段要看的是窗口本身，不需要固定时钟。

写这份清单时，托盘、置顶小窗和边缘胶囊还没合进来。结果先空着。开机自启、提醒、完整操作记录页不在这次范围内。

| 步骤 | 期望 | 结果 |
| --- | --- | --- |
| 打开开发版 | 能看到无边框的主窗口 | 未在本机执行 |
| 点主窗关闭 | 主窗消失。托盘图标还在。任务管理器里进程还在，程序没有退出 | 未在本机执行 |
| 在托盘菜单里选「打开」或「打开主窗」 | 主窗回来，还是刚才那个程序 | 未在本机执行 |
| 在托盘菜单里选「退出」 | 进程结束。托盘图标消失。要再用，必须重新启动 | 未在本机执行 |
| 重新打开后，从入口打开置顶小窗，再打开记事本或其他普通窗口盖上来 | 置顶小窗仍在其他窗口上面 | 未在本机执行 |
| 拖动置顶小窗，再关掉它，然后从原来的入口再打开 | 拖的时候能跟着走。关掉后能再打开 | 未在本机执行 |
| 用「隐藏到边缘」或同等入口让胶囊出现 | 屏幕边缘出现胶囊 | 未在本机执行 |
| 点击胶囊 | 回到主窗 | 未在本机执行 |
| 折叠主窗，再展开 | 折叠后高度或内容区变了。展开后回到折叠前的内容和高度 | 未在本机执行 |
| 把主窗拖到屏幕一角，用托盘「退出」彻底退出，再启动开发版 | 主窗仍在那一角附近。差几个像素可以接受 | 未在本机执行 |
| 打开置顶小窗，在主窗把一条进行中的计划标成完成或跳过 | 置顶小窗上的「正在执行」或列表在合理时间内跟着变，不用手动刷新 | 未在本机执行 |
| 按住主窗拖一段再松手 | 拖的时候不明显卡死。松手后外观恢复，透明或模糊回来 | 未在本机执行 |
