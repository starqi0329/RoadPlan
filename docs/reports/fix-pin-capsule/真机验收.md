# 真机验收

在自己的 Windows 上运行这条合进之后的开发版。看的是置顶小窗和边缘胶囊是不是真的出现。浏览器里的演示浮层不算通过。提醒、导出、开机自启不在这次范围内。

写这份清单时，修复还没合进来。结果先空着。请准备一个普通窗口（例如记事本）用来看置顶，并打开任务管理器看进程。

| 步骤 | 期望 | 结果 |
| --- | --- | --- |
| 打开开发版 | 主窗在。顶栏能分清「置顶」和「胶囊」 | 未在本机执行 |
| 点「置顶」 | 出现一扇独立的小窗，不是整页主壳，也不是一大块空白。它压在记事本上面。里面能看到正在进行的计划，或一句表示现在没有进行中计划的话。成功时有一句短提示 | 未在本机执行 |
| 拖这扇置顶窗，关掉，再点「置顶」 | 拖的时候跟着走。关掉后没有了。再点能再出现，并且仍在最前 | 未在本机执行 |
| 点「胶囊」 | 屏幕边缘出现胶囊。主窗收进托盘，进程还在。胶囊没有跟着主窗一起消失。成功时有一句短提示 | 未在本机执行 |
| 点胶囊 | 主窗回来，里面是原来的顶栏、左轨和主区。胶囊可以再收起 | 未在本机执行 |
| 若「置顶」或「胶囊」打不开 | 界面有一句失败说明。主窗还在。不会变成主窗和副窗都没了 | 未在本机执行 |
