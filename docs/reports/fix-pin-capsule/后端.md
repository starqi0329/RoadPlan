# 汇报

## 给人看的产出

### 这一阶段交出了什么

点「置顶」应能真正弹出一条始终在最前的横条小窗；点「胶囊」应能在屏幕边缘出现窄条，再藏主窗时胶囊还在。创建或显示失败会报错，不再假装成功。

### 打开窗口能看到什么

这一阶段没有新的主界面画面。副窗用横条置顶（约 320×96）和窄竖胶囊（约 56×160），都无系统边框、始终最前。

### 点哪里、会发生什么

- 点「置顶」→ 创建/显示 `pin` 窗，带 `?window=pin`，始终最前并可聚焦；旧的竖向大尺寸会被改成横条（位置保留）。
- 点「胶囊」→ 创建/显示 `capsule` 窗，带 `?window=capsule`，跳过任务栏但必须可见；成功后再藏主窗时，会按标志再确认胶囊仍显示、仍置顶。
- 创建失败或窗句柄丢失 → `not_found` / `internal`，不会只改「可见」标志假装开了。

### 还没做什么

- 前端首屏角色路由与成功 toast（前端任务包）
- 提醒、导出、开机自启

## 改了哪些文件

- `src-tauri/src/window_layout.rs`：默认置顶改为横条 320×96；置顶最小 200×72、横条高上限 120；`resolve_pin_frame` / `resolve_capsule_frame`；单测覆盖默认几何与旧竖窗替换
- `src-tauri/src/window_ops.rs`：副窗 URL `index.html?window=pin|capsule`；显示前套用可用几何 + `alwaysOnTop` + `show`（置顶再 `focus`）；失败不更新可见标志；`hide_main_to_tray` 后按标志补显示置顶/胶囊

capabilities 已有 create/show/hide/always-on-top/skip-taskbar，本刀未再增权限。未改最小化/托盘权威路径（仅藏主窗后补显副窗）。未改契约。

新增依赖：无。
