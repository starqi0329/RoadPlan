# 真机验收

在自己的 Windows 上运行这条热修合进之后的开发版。看的是主窗还在不在，不是新功能。提醒、导出、开机自启不在这次范围内。

写这份清单时，布局校验和折叠修复还没合进来。结果先空着。

| 步骤 | 期望 | 结果 |
| --- | --- | --- |
| 打开开发版 | 能看到应用自己的顶栏、左轨，以及日视图或一句空状态说明。不是整扇空白窗 | 未在本机执行 |
| 点折叠 | 仍能认出顶栏。窗口变成矮的一条，不是内容被清掉后还占着整扇空白 | 未在本机执行 |
| 再点展开 | 左轨和日视图（或空状态说明）回来，高度恢复到能正常使用 | 未在本机执行 |
| 点应用内关闭，再从托盘选「打开」或「打开主窗」 | 主窗回到屏幕里。不是只有几十像素高，也没有被甩到屏幕外面。里面的顶栏和内容还在 | 未在本机执行 |
| 确认当前是展开的，用托盘「退出」结束进程，再启动开发版 | 仍是展开的。能看到左轨和主区，不是只剩一条顶栏或整窗空白 | 未在本机执行 |
| 完全退出后，把 `%AppData%\com.roadplan.app\window-layout.json` 里的主窗改成横坐标和纵坐标都是 -16000、高度 25，并且是折叠，再启动 | 不会打开成那条又矮又在屏外的空壳。窗口是展开的，能看到顶栏、左轨和主区 | 未在本机执行 |
