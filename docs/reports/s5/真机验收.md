# 真机验收

在自己的 Windows 上运行切片 5 合进 `slice/5` 之后的开发版。看操作记录时不必固定时钟。看「关闭进托盘」时要打开任务管理器。

写这份清单时，顶栏「审」还没合进来，主窗和置顶小窗也还带着系统标题栏。结果先空着。开机自启和提醒不在这次范围内。

| 步骤 | 期望 | 结果 |
| --- | --- | --- |
| 打开开发版，看主窗外围 | 没有 Windows 自带的那条标题栏，也没有系统的最小化、最大化、关闭。只有应用自己的顶栏 | 未在本机执行 |
| 按住应用内顶栏拖一段 | 主窗跟着移动 | 未在本机执行 |
| 点应用内顶栏的关闭 | 主窗消失。托盘图标还在。任务管理器里进程还在，程序没有退出 | 未在本机执行 |
| 在托盘菜单里选「打开」或「打开主窗」 | 主窗回来 | 未在本机执行 |
| 打开置顶小窗，看它的外围 | 同样没有系统标题栏，没有系统的最小化、最大化、关闭 | 未在本机执行 |
| 让边缘胶囊出现 | 胶囊仍然没有系统标题栏 | 未在本机执行 |
| 新建或完成一条计划，再点顶栏「审」 | 列表最上面是刚才这条。能看到时间、做了什么、对象名字，以及一段普通文字摘要。没有评分 | 未在本机执行 |
| 再做几次会留下记录的操作，然后点「加载更早」或滚到列表下面 | 更早的记录接在后面。已经显示过的不会再重复一条。没有更早的记录时，有一句说明 | 未在本机执行 |
| 若打开「审」时一条记录都没有 | 有一句空状态说明，不是一片空白。若打开时已经有记录，这一条记「不适用」 | 未在本机执行 |
| 打开一条计划的备注，改几个字，点取消，再打开「审」 | 没有因为这次取消多出一条记录 | 未在本机执行 |
