## 给人看的产出

### 这一阶段交出了什么

本机写下的操作可以按时间从新到旧翻页查看了。主窗和置顶小窗去掉了 Windows 自带标题栏（无系统边框）；关掉主窗仍然进托盘，不会退出程序。

### 打开窗口能看到什么

这一阶段没有新的窗口画面（操作记录列表由前端接线）。主窗 / 置顶窗启动后不再带系统标题栏，拖动靠界面里的自定义顶栏。

### 点哪里、会发生什么

没有新按钮可点。用户能感受到的变化是：

- 新建、完成、改期、复盘等写操作留下的记录，可以按时间倒序一页页往更早翻。
- 主窗关闭 → 仍进托盘，进程不退出；托盘「退出」才真正关掉。
- 主窗和置顶窗没有系统边框；胶囊本来就是无边框，保持不变。

### 还没做什么

- 开机自启、提醒、云同步
- 亚克力 / 系统模糊本身（`set_dragging` 仍只发 `dragging-changed` 给前端）

这一阶段没有界面。
