# 真机验收

在自己的 Windows 上运行这个切片合进 `slice/1` 之后的开发版。发布版会忽略 `SHIXU_FAKE_NOW`，不要用发布版对时间。

打开程序前，把当前时间固定成契约里的示例时刻，避免等到真实的 11:30：

`SHIXU_FAKE_NOW=2026-11-26T10:42:00+08:00`

结果先空着。这一份清单在写测试时，窗口里还没有一天的计划，按钮还点不了。

| 步骤 | 期望 | 结果 |
| --- | --- | --- |
| 用上面的固定时间打开程序，看窗口上的时间 | 停在 2026-11-26 10:42，不会自己往前走 | 未在本机执行 |
| 看这一天有没有计划 | 没有计划时有一句说明，并告诉下一步怎么新建。不是一片空白 | 未在本机执行 |
| 新建一条今天 11:30–12:00 的工作计划，标题自己起 | 它显示为还没开始。完成不能点，或者点了会说明还没到时间。这条计划仍是没开始 | 未在本机执行 |
| 新建一条今天 10:00–11:00 的工作计划 | 它显示为正在进行，可以完成 | 未在本机执行 |
| 把 10:00 那条标成完成 | 变成已完成，不标「迟」 | 未在本机执行 |
| 新建一条今天 09:00–10:00 的工作计划 | 显示为已经过了结束时间，没有自动变成完成 | 未在本机执行 |
| 把 09:00 那条补记完成 | 变成已完成，并标「迟」 | 未在本机执行 |
| 再新建一条还没处理的计划，选择跳过，可以写原因 | 变成已跳过。已完成的那条不能再跳过 | 未在本机执行 |
| 对一条已完成的计划撤销 | 完成结果清掉，按 10:42 重新显示成进行中或已过期 | 未在本机执行 |
| 再建一条和已有计划时间叠在一起的计划并保存 | 能看到和哪一条重叠，两条都还在 | 未在本机执行 |
| 把一条还没处理的计划改到 2026-11-27，标题也可以一起改 | 今天原来那条变成已跳过，写明已改期到 2026-11-27。27 日有一条新计划，内容是刚提交的那份 | 未在本机执行 |
| 把一条已经完成、并且写了备注的计划复制到另一天 | 另一天有一条新计划。它没有完成结果，备注是空的。原来那天那条还是完成，备注还在 | 未在本机执行 |
| 删除一条还没处理的计划 | 这一天的列表里不再有它 | 未在本机执行 |
| 再删一条已经完成的计划 | 删不掉，它还在 | 未在本机执行 |
| 新建一条核心计划，不选周目标就保存 | 保存失败，并说明要选周目标。列表里没有这条 | 未在本机执行 |
| 完全退出程序，再用同一个固定时间打开，回到 2026-11-26 | 刚才留下的计划都还在，完成或跳过的结果也还在 | 未在本机执行 |
| 看正在进行的那一条 | 能看出现在该做哪一条（高亮或当前时间线）。这一条要等人眼看，自动化没有覆盖画面 | 未在本机执行 |
