## 给人看的产出

### 这一阶段交出了什么

顶栏右侧按钮改成一眼能懂的短中文：`审` / `最小化` / `胶囊` / `置顶` / `×`。去掉了「▢ / 口」以及「◌」「⌃」这类费解符号。每个按钮仍有中文 `title`（悬停说明）。

### 打开窗口能看到什么

展开态顶栏窗控区直接显示文字按钮，不再出现方块「口」符号。

### 点哪里、会发生什么

本分支**只改文案与样式**，不改点击行为：

- `审` → 仍打开操作记录  
- `最小化` → 仍走原有顶栏第二键逻辑（最小化语义由 hotfix 1 负责；本分支不改其实现）  
- `胶囊` / `置顶` / `×` → 行为与改前相同；× 二次关闭留给 hotfix 3

### 还没做什么

- 未改最小化语义、未修 × 二次关闭
- 未做提醒 / 导出 / 开机自启
