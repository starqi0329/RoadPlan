## 没跑成的检查

Rust 的 `cargo test`、clippy，以及 `pnpm bindings` 没有跑。

本机有 Rust 和 WebView2，Visual Studio 里没有 C++ 编译器。安装“使用 C++ 的桌面开发”时，系统的授权窗口被取消了，所以链接器不存在，Rust 代码还没编译。

装好之后在仓库根目录运行 `pnpm verify`。这一步也会生成真正的 `src/bindings.ts`。生成后如果和现在的占位文件不同，需要再提交一次。

窗口技术验证（透明、置顶、拖动、双窗口同步）也要等编译器可用后再做，放在 `spike/窗口验证`，不合进 `main`。
