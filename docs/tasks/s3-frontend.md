# 任务包

- 角色：前端
- 切片：3
- 分支：`fe/s3-review-tomorrow`
- 契约版本：0.2.2

## 目标

做出复盘界面：上午 / 下午 / 晚间时段复盘与目标复盘可写笔记、看保存时的统计；未到点的时段明确提示「该时段尚未开始」，不能假装已保存。晚间复盘提供「明天」计划区：复制今天、改期到明天、新建明天计划。日计划支持在「今天 / 明天」（或等价的日期切换）之间查看，以便核对排好的明天。

## 允许修改

- `src/`（不要改 `src/bindings.ts`）
- `index.html`、`vite.config.ts`、`package.json` 与锁文件
- 前端配置（如有必要）
- 自己的 `docs/reports/`

## 不要做

- 不要手写命令名；只用 `src/bindings.ts` 里的 `commands`
- 不要在前端重算复盘统计快照；展示后端返回的 `stats`
- 不要做复盘评分、大模型结论、置信度（原型里有也不要做）
- 不要做置顶小窗、托盘、胶囊、操作记录浏览页

## 界面最低要求

- 日计划（或主界面）有进入上午 / 下午 / 晚间复盘的入口
- 时段未开始：显示「该时段尚未开始」，保存不可用或保存后明确失败提示
- 可写复盘笔记并保存；再次打开能看到上次内容与统计（计划数 / 完成 / 跳过 / 逾期 / 专注分钟）
- 目标页可对某个目标写复盘；目标复盘可有多份（列表新的在前）
- 晚间复盘有明天计划区：至少支持复制今天的计划到明天、把未完成改到明天、新建明天的计划（调用已有计划命令）
- 能切换查看明天的日计划，确认排程结果
- 开发版走真实 Tauri；浏览器演示若保留须标明不写库
- 空状态有一句说明和下一步
