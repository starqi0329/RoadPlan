# 任务包

- 角色：前端
- 切片：layout（布局对齐）
- 分支：`fe/layout-prototype-shell`
- 契约版本：0.2.3

## 目标

把当前「整页切换」的壳，改成与原型一致的主窗骨架；已实现的日计划、目标、复盘、今天/明天能力全部迁进去，布局、留白、浅色玻璃感对齐原型。

## 允许修改

- `src/`（不要改 `src/bindings.ts`）
- `index.html`、`vite.config.ts`、`package.json` 与锁文件（仅在确有必要时）
- 自己的 `docs/reports/`

## 不要做

- 不要改契约、后端、测试产品逻辑
- 不要做复盘评分、大模型、云同步、真实置顶/托盘/胶囊（切片 4）
- 不要删掉已有业务能力来「图省事」；可以重组组件，但完成 / 跳过 / 目标 / 复盘 / 明天排程要仍可用
- 不要手写命令名；继续只用 `bindings` 里的 `commands`

## 对照原型：必须对齐的骨架

对照文件：`docs/prototype/计划时间表-高保真界面原型.html`（只看布局与结构，不抄被否掉的功能文案）。

### 1. 整体主窗

- 一块圆角玻璃主窗（约原型比例：宽主区 + 左轨），不是浏览器整页白底 + 顶 Tab。
- CSS 变量与浅色玻璃感贴近原型（已有变量可复用/微调）。

### 2. 顶栏（titlebar）

从左到右大致为：

| 区域 | 内容 |
| --- | --- |
| 品牌 | Logo +「时序」；副标题不要写「macOS 原型」，可写产品短名或省略 |
| 日期 | 当前查看日期（如 `2026.11.26`）+ 简短周期说明（如周几 / 本月第几周，可用已有 `periods`） |
| 正在执行 | 有进行中计划时显示标题；没有则显示「当前没有进行中的计划」 |
| 右侧按钮 | 可放审计 / 折叠 / 隐藏的**视觉占位**；本刀不接真实窗口 API |

### 3. 主体双栏（app-body）

**左侧轨（rail）约 236px：**

- 标题：「计划层级」或等价文案
- 四项层级：年内计划 / 月内计划 / 周内计划 / 每日时间表  
  - 点年 / 月 / 周 → 右侧切到对应目标视图（复用现有目标能力，按层级过滤或定位）  
  - 点每日 → 右侧日时间轴  
- 下方「当前执行所属链路」：有进行中（或选中）核心计划时，尽量展示年→月→周→计划；没有则一句空状态，不要空白一块

**右侧主区（main）：**

- **日视图**：主头（「今日/明日时刻计划」、添加、筛选、图例）；时间轴；**不要**再用整页顶 Tab 切「目标」
- **层级视图**：面包屑或标题 + 目标列表/树（现有目标增删改、复盘入口迁到这里）
- 日视图可保留「今天 / 明天」切换，放在主头附近，样式融入原型，不要另起一套导航

### 4. 底栏复盘（reviewbar）— 仅日视图

- 三个入口：上午复盘 / 下午复盘 / 晚间（或睡前）复盘，样式贴近原型底栏按钮条
- 未到点：副文案「到点后展开」或「该时段尚未开始」；已保存可显示「已保存」等短状态（**不要**收益分数）
- 点开仍用现有复盘抽屉/面板；晚间仍带明天计划区
- 从主区里零散的「时段复盘」大按钮条迁到这条底栏（主区可保留轻量入口，但底栏必须有）

### 5. 状态条（statusbar）

- 底下一行小字：本地存储、完成度（如当日完成/总数）等  
- **不要**写「云同步」「今日收益预估」分数

### 6. 交互与能力保持

- 计划：新建、完成、跳过、状态与按钮不重叠（切片 2 已修，勿回退）
- 目标：新建、进度、删前三数、恢复、核心挂周目标
- 复盘：未到点不可装保存；统计用后端字段
- 空状态有一句说明和下一步
