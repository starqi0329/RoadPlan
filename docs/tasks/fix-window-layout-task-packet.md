# 窗口布局稳定 · 任务包总览

- 代号：`fix-window-layout`（S5 之后的热修刀，不是新功能切片）
- 主题：主窗别再「消失 / 变空壳」；折叠、关进托盘、再打开后尺寸正常
- 契约版本：0.3.1（尽量不改；不够用写变更申请）
- 分支前缀：`be/fix-…`、`fe/fix-…`、`qa/fix-…`（英文）

## 背景（给人看）

真机出现过：主窗被存成折叠、高度只有几十像素，还被甩到屏幕外（约 `-16000`），再打开就像「里面什么都没了」。假桌面已去掉；这一刀只管**窗口几何与折叠壳**别再把用户弄丢。

PRD 下一阶段是「自己用 4 周再谈提醒/导出」。本刀**不做提醒、导出、开机自启**。

## 这一刀要交出什么

1. **后端**：持久化布局时拒绝或修复明显不可用的几何（过小、非有限值、明显在屏外）；启动读到坏档时回退默认，不要静默开出 25px 高的窗。关进托盘 / 折叠不要把「隐藏后的废坐标」当成下次正常尺寸写死。  
2. **前端**：真机折叠时不要把空内容区拉成「整窗空白壳」；展开后左轨和日视图仍在。浏览器演示假桌面可保留。  
3. **测试**：对照 + 真机清单覆盖：折叠→展开、关闭进托盘→打开、杀进程再开，主窗都要能看见完整界面。
