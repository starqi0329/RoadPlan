## 这一切片要交出什么

主窗可折叠、可拖（拖时减弱透明）、点关闭进系统托盘而不是退出；托盘可恢复主窗、可真正退出。能打开置顶小窗（始终最前，显示此刻相关简讯并可拖）。能显示边缘胶囊，点一下回到主窗。三个窗口读同一份数据，改计划后都会跟着变。窗口位置重启后还在。

操作记录浏览页、开机自启不在本切片。
