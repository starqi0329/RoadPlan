# 任务包

- 角色：前端
- 切片：2
- 分支：`fe/s2-goal-tree`
- 契约版本：0.2.1

## 目标

做出目标树界面：能看年 / 月 / 周目标与进度；能新建、改状态、删前确认影响、看已删除并恢复。日计划新建「核心」时可选择本周周目标。并修复切片 1 日计划卡片上的布局 bug。

## 允许修改

- `src/`（不要改 `src/bindings.ts`）
- `index.html`、`vite.config.ts`、`package.json` 与锁文件
- 前端配置（如有必要）
- 自己的 `docs/reports/`

## 不要做

- 不要手写命令名；只用 `src/bindings.ts` 里的 `commands`
- 不要在前端重算状态、进度口径、删除影响三个数字（用后端返回）
- 不要做复盘抽屉、置顶小窗、托盘、胶囊、操作记录浏览页
- 不要做原型里被 PRD 否掉的功能

## 必须修复（切片 1 遗留）

日计划卡片上，状态文案（如「未开始」「进行中」「已过期」）与「完成」「跳过」等操作按钮**视觉重叠或互相挡住**。要改布局，使：

- 状态文案和操作按钮分区清楚，任何常见宽度下都不叠字、不挡点击
- 未开始时「完成」仍不可用（或点了有明确提示），行为不变，只修呈现

汇报里附修前说明或修后截图，写清打开看到什么、点哪里、结果是什么。

## 界面最低要求

- 目标树或等价列表：空状态有一句说明和下一步
- 新建年 / 月 / 周目标（周挂月、月挂年）；展示 progress
- 里程碑型：能增改里程碑状态；累积型：显示 done / total（来自后端）
- 删除前展示 `goalsArchived` / `plansDeleted` / `plansKept`，确认后才删
- 已删除列表可恢复
- 日计划新建支持「核心」，并要求选择未删除的周目标（无周目标时有明确提示）
- 开发版桌面程序走真实 Tauri 命令；浏览器演示层若保留，必须继续标明「不会写入本地库」
