# 切片 3 任务包总览

- 切片：3
- 主题：复盘与明天
- 契约版本：0.2.2
- 分支前缀：`be/s3-…`、`fe/s3-…`、`qa/s3-…`（英文）

## 这一切片要交出什么

用户能对上午 / 下午 / 晚间做时段复盘（未到点不能写），也能对目标写复盘笔记；保存时记下当时的统计快照，之后改计划不会改这份快照。晚间复盘里能排明天的计划：复制今天的、把没做完的改到明天、新建明天的计划。

没有复盘评分、没有大模型结论。窗口置顶 / 托盘 / 胶囊、操作记录浏览页都不在本切片。
