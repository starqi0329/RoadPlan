# 布局对齐任务包总览

- 切片代号：`layout`（插在切片 3 与切片 4 之间，不改业务契约）
- 主题：主窗内部布局贴齐原型骨架
- 契约版本：0.2.3（本刀不改契约）
- 分支：`fe/layout-prototype-shell`（英文）

## 这一刀要交出什么

打开开发版后，**主窗内部结构**应一眼能对上原型 `docs/prototype/计划时间表-高保真界面原型.html`：

顶栏 → 左侧层级轨 + 右侧主区 →（日视图时）底栏复盘入口 → 底状态条；目标和日计划在同一窗内切换，不再用整页「日计划 | 目标」顶栏翻页。

已有能力（计划、目标、复盘、今天/明天）都要还能用，只是换壳、归位。

## 角色

| 角色 | 文件 | 建议分支 |
| --- | --- | --- |
| 前端 | [layout-frontend.md](layout-frontend.md) | `fe/layout-prototype-shell` |

本刀**不派后端**。测试可选：人按汇报截图对照原型，不强制新自动化。

合并：组织者复核前端分支后合进 `main`（可用 `slice/layout` 再进 `main`）。

## 共同约束

- 视觉以原型为准；功能以契约 / PRD 为准。
- 原型里不要做的：复盘评分、大模型结论、云同步、「应用到次日」、过了时间自动完成、置顶小窗 / 托盘 / 胶囊真实窗口行为（留给切片 4）。
- 顶栏可留出折叠 / 隐藏 / 审计按钮的**占位**，点击可先 toast「下一切片再做」或禁用，不要假实现系统托盘。
