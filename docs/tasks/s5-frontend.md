# 任务包

- 角色：前端
- 切片：5
- 分支：`fe/s5-audit-frameless`
- 契约版本：0.3.0

## 目标

1. **操作记录抽屉/面板**：顶栏「审」打开；列表展示时间、动作、对象名、纯文本摘要；支持加载更多（`list_audit` + `beforeId`）。空状态有一句说明。  
2. **配合无边框主窗**：系统标题栏去掉后，自定义顶栏是唯一拖动与关闭入口；样式贴齐原型悬浮窗（圆角、阴影），不要再像「套在系统框里」。置顶小窗同步无系统框观感。

## 允许修改

- `src/`（不要手改 `src/bindings.ts`）
- 必要前端配置、`package.json`（仅必要时，汇报写理由）
- 自己的 `docs/reports/`

## 不要做

- 不要做开机自启、提醒、评分、云同步
- 不要手写命令名；只用 `commands`
- 不要在前端伪造操作记录（真机走 `list_audit`；浏览器演示可 mock，须标明）

## 界面最低要求

- 顶栏「审」打开操作记录；再点或关闭按钮可收起
- 每条：时间、类型/动作、对象标题、摘要（前端只排版，不改摘要语义）
- 底部或滚动到底「加载更早」；没有更多时提示
- 写一条计划/目标/复盘后，打开列表能看到对应新记录（依赖 `data-changed` 含 `audit` 时刷新）
- 无边框后：顶栏可拖动主窗；「×」仍 `hide_main_to_tray`；最大化若需要可用 Tauri 窗口 API，没有系统框按钮也要可用或明确不做最大化
- 保持左轨 + 日视图骨架；不要退回整页 Tab

## 跳转（能做多少做多少）

PRD §8.7：从记录点到对象时，关掉抽屉、解除折叠/隐藏，高亮目标行约 1.8 秒。若本切片时间紧，至少支持点计划类记录切到日视图并尽量高亮；做不到的写进汇报「还没做」。
