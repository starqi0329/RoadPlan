## 1. 概述

时序是一款常驻 Windows 桌面的半透明计划表。它把年、月、周目标和每天的计划串成一条链，显示此刻该做什么，并在晚上把今天的结果排进明天。

一句话：看得见此刻，追得到目标，复盘落到明天。

## 2. 背景

计划写进表格或待办之后，常见三个断点：写完就被别的窗口挡住；年、月、周目标和当天的事对不上；勾完就结束，不会根据今天调整明天。

第一版先给产品负责人自己用。上面三个断点来自本人的使用经历，还没有访谈。这是假设，用第 3 节的结果来验证。

## 3. 目标

连续使用 4 周后看三个结果。数字是假设，使用前可以改：

| 编号 | 结果 | 算法 |
| --- | --- | --- |
| KR1 | 每周至少 5 天处理过计划 | 当天有计划被标记完成或跳过的天数 |
| KR2 | 晚间复盘完成率至少 70% | 有晚间复盘的天数 / 有计划的天数 |
| KR3 | 核心计划处理率至少 80% | 核心计划里被完成或跳过的比例 |

这些都从本地数据库计算，不上报。

## 4. 用户

有中长期目标、每天自己安排时间的知识工作者。限制：只支持 Windows 10/11，单用户，数据只在本机，不登录，不同步。

## 5. 价值

用户要让每天的时间推进重要目标，并且每天能改进一点。现在用日历、待办或纸笔，开始工作后计划被挡住，目标写在别处。时序用置顶时间轴显示此刻，核心计划挂到周目标并自动累计，晚间复盘时直接排出明天。

## 6. 范围

### 6.1 第一版要做

- 主窗口：拖动、折叠、隐藏到屏幕边缘的胶囊。关闭进入系统托盘，不退出。
- 置顶小窗和托盘。
- 按日期查看的时间轴，上午、下午、晚间三段。状态由时间推导。完成、跳过、补完成、备注。
- 新建、编辑、改期、复制到另一天。时间重叠只提示。
- 年、月、周目标。里程碑或累积次数。删除前确认，然后归档，可以恢复。
- 上午、下午、晚间复盘，以及目标复盘。晚间复盘里可以排明天的计划。
- 操作记录。当前计划到年目标的链路。

### 6.2 稍后做

开机自启、数据导出、查看上一个周期。

### 6.3 不做

到点提醒、复盘评分、大模型分析、重复计划模板、多用户、云同步、macOS、Linux、微信推送。提醒等用过 4 周再决定。

## 8. 方案

### 8.1 窗口

主窗口是无边框半透明窗。置顶小窗和边缘胶囊是另外两个系统窗口。三个窗口读同一份数据，任一处修改后其他窗口跟着变。

拖动时暂时关掉透明效果，松手后恢复。窗口位置在重启后保留。点关闭只是进托盘，托盘菜单里才有退出。

### 8.2 日视图

日期可以前后切换。时段按计划的开始时间：0:00–12:00、12:00–18:00、18:00–24:00。没有计划的时段不显示。筛选有全部、待处理、已完成，统计按可见计划重算。状态每分钟刷新。

### 8.3 计划

类型是核心、工作、日常、复盘。核心必须选择计划当天所在周的周目标，其他类型可以不选。结束晚于开始，不跨零点。默认 09:00–10:00。

待开始和进行中可以编辑。其余只能改期。改期提交新的日期、时间和完整内容，生成新计划，原计划记为"已跳过 · 已改期"。复制到另一天时，新计划没有处理结果，备注清空。

备注有保存、取消、清除。空白保存等于清除。取消不写操作记录。

### 8.4 状态

没有处理结果时不会自动变成完成。还没到开始是待开始，进行中是开始到结束之间，过了结束是逾期。过去的日期按已过结束处理，未来的日期按未开始处理。逾期可以补完成，并标"迟"。已完成或已跳过可以撤销。

### 8.5 目标

年独立。月必须挂年。周必须挂月。周按每月 1–7 日为第一周，依次到月末，不跨月。29 日以后是第五周。平年 2 月没有第五周。

进度二选一：里程碑的完成数，或累积次数。累积次数等于挂在这个目标及其下级下、已完成的计划条数。

删除前先给出三个数：归档几个目标、删除几条未结束的计划、保留几条历史计划。确认后未结束的计划删除，已逾期、已完成、已跳过的计划保留并仍挂在原目标上。已删除视图里可以查看和恢复。只是不想继续做，用"放弃"，不删除。

### 8.6 复盘

时段复盘每个时段一份，再次保存覆盖。目标复盘可以有多份。内容是笔记，加上保存当时的统计：计划数、完成数、跳过数、逾期数、已完成计划的分钟数。没有评分。没开始的时段显示"该时段尚未开始"。

晚间复盘有明天的计划区，可以复制今天的计划、把没做完的改到明天、新建或修改明天的计划。

### 8.7 操作记录和跳转

每次写操作一条记录，包含时间、类型、对象名和纯文本摘要。取消编辑不记录。

导航、面包屑、下级、链路、胶囊、置顶小窗这六个入口跳转时，先关掉抽屉，解除隐藏和折叠。跳到的那一行高亮 1.8 秒。

### 8.8 空状态

没有目标、没有下级、选中的日期没有计划、还没有月目标或周目标、时段还没开始，都要有一句说明和下一步，不能是空白。

### 8.9 技术

Tauri 2，只支持 Windows 10/11。界面用 React 和 TypeScript。会改变数据或影响提醒的规则放在 Rust，当前时间以参数传入。只影响显示的分组、筛选和百分比放在前端。数据用本地 SQLite，从第一个功能切片开始。前后端类型由 Rust 生成。

性能数字是假设，技术验证后确认：冷启动 2 秒内看到主窗口，空闲内存低于 150 MB，拖动不卡。最小字号 12px。

| 项 | 内容 |

| 假设 | 每天愿意花几分钟规划和复盘 |

## 9. 发布

先做窗口技术验证，再冻结契约，然后按切片开发：计划与状态、目标与累积、复盘与明天、窗口与托盘、操作记录。每个切片先合到 `slice/N`，复核和真机验收通过后再进 `main`。之后自己用 4 周，再决定提醒和导出。

## 10. 验收清单

窗口的拖动、折叠、胶囊、托盘、置顶和多窗口同步。未开始不能完成，逾期和补完成，不会自动完成。核心计划必须挂周目标。重叠只提示。改期留下原计划。周不跨月。累积计数。删除前的三个数字和归档恢复。复盘快照不随后续修改变化。每次写操作恰好一条记录。六个跳转入口都能落地。
